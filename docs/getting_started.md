# はじめかた（セットアップ手順）

このページのとおりに進めれば，**プログラミングの知識がなくても**BOTを動かせます．

パソコンに何かをインストールする必要はありません．すべてブラウザ上の操作だけで終わります．

かかる時間の目安は **30分〜1時間**です．

## はじめに知っておくこと

### このBOTは何をするか

Googleカレンダーに入っている予定を，毎朝Discordへ自動で送ります．

```text
Googleカレンダー          Google Apps Script            Discord
  今日の予定      →      毎朝1回，予定を読んで    →     メッセージが届く
  明日の予定             メッセージを組み立てる
```

### Google Apps Script とは

**Googleが無料で提供している，プログラムを動かす場所**です．

自分のパソコンを起動しておく必要はありません．パソコンの電源が切れていても，Googleのサーバー上で毎朝勝手に動きます．

以降このページでは **GAS**（ガス）と略します．

### 費用について

**すべて無料です．** Googleアカウントがあれば使えます．クレジットカードの登録も要りません．

### 用語

| 言葉 | 意味 |
| --- | --- |
| Webhook（ウェブフック） | 外部のプログラムからDiscordへメッセージを送るための，専用の送信先URL |
| GAS | Google Apps Script．Googleのサーバー上でプログラムを動かす仕組み |
| トリガー | 「毎朝9時に実行する」のように，決まったタイミングでプログラムを動かす設定 |
| ラベル | Googleカレンダーで予定に付ける色のこと．このBOTでは色に名前を付けて使います |

## 手順1. Discord の Webhook URL を取得する

BOTがDiscordへメッセージを送るための「送信先の住所」を作ります．

1. Discordを開き，通知を受け取りたい**チャンネル名の上にカーソルを置きます**．

2. 歯車アイコン（⚙️ チャンネルの編集）をクリックします．

3. 左側のメニューから **「連携サービス」** を選びます．

4. **「ウェブフックを作成」** をクリックします．

5. 名前を分かりやすいものに変えます（例：`カレンダーBOT`）．

    ここで設定した名前とアイコンが，Discordに届くメッセージの送信者として表示されます．

6. **「ウェブフックURLをコピー」** をクリックします．

7. コピーしたURLを，メモ帳などに一時的に貼り付けておきます．

    次のような形式の長いURLです．

    ```text
    https://discord.com/api/webhooks/1234567890/AbCdEfGh...
    ```

> **とても重要**
> このURLを知っている人は，**誰でもあなたのチャンネルへ投稿できます．**
>
> - SNSやブログに貼らない
> - GitHubなど公開の場所にアップロードしない
> - 人に見せない
>
> もし誤って公開してしまった場合は，**Discordの同じ画面でそのウェブフックを削除し，作り直してください．**
> 削除するまで，URLを知っている人は投稿し続けられます．

## 手順2. Googleカレンダーにラベルの色を付ける

**すべての予定を通知したい場合は，この手順は飛ばして構いません．**

「研究の予定だけ通知したい」「バイトの予定は通知したくない」のように，**予定を種類ごとに絞り込みたい場合**だけ必要です．

### しくみ

Googleカレンダーでは，予定ごとに色を変えられます．このBOTは，**その色を見て予定を仕分けます．**

```text
予定に付けた色        BOTが使う名前
  紫色         →      会社タスク
  緑色         →      アルバイト
  赤色         →      重要
```

色そのものには名前がないので，**「この色は，こういう名前で呼ぶ」という対応をBOTに教える**必要があります．その作業は手順6で行います．

### いま行うこと

1. ブラウザで [Googleカレンダー](https://calendar.google.com/) を開きます．

2. 種類を分けたい予定をクリックします．

3. 鉛筆アイコン（編集）をクリックします．

4. 予定名の左にある**色の丸**をクリックし，好きな色を選びます．

5. **保存**します．

6. 同じ種類の予定には，同じ色を付けます．

> **注意：同じ色を使い回さないでください**
> BOTは色だけで種類を見分けています．
> **別々の種類に同じ色を割り当てると，区別できなくなります．**
>
> 色はパレットから選んでも，カラーピッカーで自分で作っても構いません．
> 種類の数に上限はありません．

### あとで使う情報をメモする

手順6で使うので，次をメモしておいてください．

| メモする内容 | 例 |
| --- | --- |
| その色に付けたい名前 | `会社タスク` |
| その色が付いている予定の**正確な件名** | `定例ミーティング` |
| その予定の日付 | `2026/07/05` |

件名は**カレンダーに表示されているとおりに**メモしてください．スペースの数まで一致している必要があります．

## 手順3. Apps Script にコードを貼り付ける

BOTのプログラムを，自分のGoogleアカウント上に用意します．

### 新しいプロジェクトを作る

1. ブラウザで [Google Apps Script](https://script.google.com/) を開きます．

2. 左上の **「新しいプロジェクト」** をクリックします．

3. 左上のプロジェクト名（`無題のプロジェクト`）をクリックし，分かりやすい名前に変えます．

    例：`カレンダー通知BOT`

### ファイルを作る

このBOTは12個のファイルでできています．1つずつ作っていきます．

1. 最初から `コード.gs` というファイルがあります．左側のファイル名の右にある**縦3点メニュー**から「名前を変更」を選び，`main` に変えます．

    > 拡張子（`.gs`）は自動で付くので，`main` とだけ入力してください．

2. `main.gs` の中身をすべて削除し，このリポジトリの [`gas/main.js`](../gas/main.js) の中身をすべてコピーして貼り付けます．

3. 左側の **「ファイル」の横の「＋」** →「スクリプト」で新しいファイルを作り，同じ要領で残りのファイルを作ります．

作るファイルは次の12個です．

| GAS上のファイル名 | コピー元 |
| --- | --- |
| `main` | [`gas/main.js`](../gas/main.js) |
| `config_calendar` | [`gas/config_calendar.js`](../gas/config_calendar.js) |
| `config_labels` | [`gas/config_labels.js`](../gas/config_labels.js) |
| `settings_resolver` | [`gas/settings_resolver.js`](../gas/settings_resolver.js) |
| `calendar_api` | [`gas/calendar_api.js`](../gas/calendar_api.js) |
| `calendar_labels` | [`gas/calendar_labels.js`](../gas/calendar_labels.js) |
| `label_registry` | [`gas/label_registry.js`](../gas/label_registry.js) |
| `reminder_builders` | [`gas/reminder_builders.js`](../gas/reminder_builders.js) |
| `calendar_formatters` | [`gas/calendar_formatters.js`](../gas/calendar_formatters.js) |
| `send_discord` | [`gas/send_discord.js`](../gas/send_discord.js) |
| `calendar_diagnostics` | [`gas/calendar_diagnostics.js`](../gas/calendar_diagnostics.js) |
| `utils` | [`gas/utils.js`](../gas/utils.js) |

> **補足**
> ファイル名の順番や並び順は動作に影響しません．GASは全ファイルをまとめて読み込みます．

> **もっと楽な方法**
> 12個を手作業でコピーするのが大変な場合は，`clasp` という道具を使うとコマンド1つで送れます．
> ただしパソコンへのインストールが必要です．興味があれば
> [開発環境の準備](development_environment.md) を読んでください．
> **この手順のままでも問題なく動きます．**

### 保存する

上部の**フロッピーディスクのアイコン**（保存）をクリックします．

## 手順4. 設定ファイルを編集する

自分用の設定を書き込みます．編集するのは **`config_calendar.gs`** と **`config_labels.gs`** の2つだけです．

### config_calendar.gs

左のファイル一覧から `config_calendar` をクリックして開きます．

#### 必ず変える項目

**1. Webhook URL**

手順1でコピーしたURLに書き換えます．

```js
webhookUrl: "DiscordのWebhook URLをここに入れる",
```

↓

```js
webhookUrl: "https://discord.com/api/webhooks/1234567890/AbCdEfGh...",
```

> **注意** `"` （ダブルクォート）は消さないでください．URLだけを差し替えます．

#### そのままでよい項目

残りは，最初はそのままで動きます．あとから変えられます．

| 設定 | 初期値 | 意味 |
| --- | --- | --- |
| `calendarId` | `"primary"` | 読み取るカレンダー．`"primary"` は自分のメインカレンダー |
| `targetEventLabels` | `false` | `false` = すべての予定を通知．絞り込みたい場合は手順6で変更 |
| `enableTomorrowReminder` | `true` | 明日の予定を通知するか |
| `enableTodayReminder` | `true` | 今日の予定を通知するか |
| `notifyIfEmpty` | `false` | 予定が0件の日も「予定はありません」と送るか |
| `showDescription` | `true` | 予定の説明欄をメッセージに載せるか |
| `descriptionMaxLength` | `80` | 説明欄を何文字で切り詰めるか |
| `calendarLinkView` | `"week"` | 末尾リンクの表示形式．`"day"` `"week"` `"month"` `"year"` |

各項目の詳しい説明は [README](../README.md) にあります．

### config_labels.gs

**すべての予定を通知する場合（`targetEventLabels: false` のまま）は，このファイルは編集不要です．手順5へ進んでください．**

絞り込みたい場合は，手順2でメモした内容を書き込みます．

**1. 通知したいラベル名を並べる**

```js
const CALENDAR_REMINDER_LABELS = [
  "会社タスク",
  "アルバイト"
];
```

**2. それぞれの色を教えるための「見本の予定」を書く**

```js
const CALENDAR_LABEL_REGISTRY_SEEDS = [
  {
    labelName: "会社タスク",
    sampleEventTitle: "定例ミーティング",
    sampleDate: "2026/07/05"
  },
  {
    labelName: "アルバイト",
    sampleEventTitle: "アルバイト",
    sampleDate: "2026/07/08"
  }
];
```

| 項目 | 書く内容 |
| --- | --- |
| `labelName` | 通知に表示したい名前．自由に決められます |
| `sampleEventTitle` | その色が付いている予定の，**カレンダー上の正確な件名** |
| `sampleDate` | その予定の日付．`2026/07/05` の形式（年/月/日） |

> **なぜ見本が要るのか**
> Googleカレンダーは，色に付けた名前をプログラムへ渡してくれません．
> そのため「この件名の予定と同じ色を，この名前で呼ぶ」という形で教える必要があります．
> 一度覚えさせれば，その見本の予定を削除しても動き続けます．

**3. 絞り込みを有効にする**

`config_calendar.gs` に戻り，1行だけ書き換えます．

```js
targetEventLabels: false,
```

↓

```js
targetEventLabels: CALENDAR_REMINDER_LABELS,
```

編集が終わったら**保存**します．

## 手順5. Discord への送信をテストする

まず，Discordへメッセージが届くかだけを確認します．

1. GASエディタ上部の**関数を選ぶプルダウン**（`main.gs` を開いた状態で表示されます）から，
   **`test_send_discord_message`** を選びます．

2. **「実行」**をクリックします．

### はじめて実行するときの許可について

初回だけ，Googleから許可を求める画面が出ます．

1. 「承認が必要です」→ **「権限を確認」**をクリック
2. 自分のGoogleアカウントを選択
3. **「このアプリは Google で確認されていません」**と表示されたら
   - 左下の **「詳細」** をクリック
   - **「（プロジェクト名）に移動（安全ではないページ）」** をクリック
4. 権限の一覧を確認し，**「許可」**をクリック

> **この警告は正常です．**
> Googleの審査を受けていない個人のスクリプトには必ず表示されます．
> このコードはあなた自身のアカウント上で動き，あなたのカレンダーとDiscordにしかアクセスしません．

求められる権限は次の3つです．

| 権限 | 用途 |
| --- | --- |
| カレンダーの表示 | 予定を読むため |
| 外部サービスへの接続 | Discordへ送信するため |
| データの保存 | 色と名前の対応を覚えておくため |

### 結果を確認する

Discordのチャンネルに次のメッセージが届いていれば成功です．

```text
【テスト送信】Googleカレンダー通知BOT からの送信確認です。
```

届かない場合は「[うまくいかないとき](#うまくいかないとき)」を確認してください．

## 手順6. ラベルをBOTに覚えさせる

**すべての予定を通知する場合（`targetEventLabels: false`）は，この手順は不要です．手順7へ進んでください．**

手順4で書いた「見本の予定」を使って，色と名前の対応をBOTに記憶させます．

1. 関数のプルダウンから **`sync_calendar_label_registry`** を選びます．

2. **「実行」**をクリックします．

3. 画面下の**「実行ログ」**を確認します．

### 成功しているとき

次のような行が，ラベルの数だけ表示されます．

```text
{"labelName":"会社タスク","colorId":"5","source":"seed", ...}
{"labelName":"アルバイト","colorId":"9","source":"seed", ...}
```

`colorId` に数字が入っていれば，その色を覚えられています．

### 失敗しているとき

```text
syncCalendarLabelRegistry_: サンプル予定が見つかりません。labelName=アルバイト, ...
```

見本の予定が見つからなかった場合です．次を確認してください．

| 確認すること | 内容 |
| --- | --- |
| 件名が完全に一致しているか | スペースの数，全角/半角も一致している必要があります |
| 日付が合っているか | 見本の日付の**前後30日**の範囲を探します |
| その予定が実在するか | 削除していないか確認してください |

```text
syncCalendarLabelRegistry_: サンプル予定から colorId を取得できませんでした。
```

予定は見つかったものの，**色が付いていません．** カレンダーでその予定に色を付けてから，もう一度実行してください．

> **色を変えたときは**
> あとから色を変更した場合は，もう一度 `sync_calendar_label_registry` を実行してください．
> 対応がおかしくなった場合は，`clear_calendar_label_registry` で一度リセットしてから実行し直せます．

## 手順7. 手動で送信してみる

本番と同じメッセージを，1回だけ手で送ってみます．

1. 関数のプルダウンから **`calendar_reminder_main`** を選びます．

2. **「実行」**をクリックします．

3. Discordを確認します．

次のようなメッセージが届きます．

```text
## 📅 本日の予定
### 2026年7月3日（金）

**14:30〜16:00**
> [会社タスク] 企画書のレビュー
> └ 先方へ提出する企画書の内容を確認し、修正点を洗い出す...続きはカレンダー

**20:00〜21:15**
> [アルバイト] アルバイト

**22:00〜23:00**
> [会社タスク] 週次進捗確認

[🔗 Googleカレンダーで確認](リンク)

---

## 📅 明日の予定
### 2026年7月4日（土）

**10:00〜12:00**
> [会社タスク] 定例会

[🔗 Googleカレンダーで確認](リンク)
```

> **何も届かないとき**
> 今日も明日も予定が0件で，かつ `notifyIfEmpty` が `false` の場合は，
> **何も送らないのが正常な動作です．**
> 実行ログに「対象予定がないためセクションを作成しません」と出ていれば正常です．
> カレンダーに予定を1つ入れてから試すと確認できます．

## 手順8. 自動送信の設定をする

毎朝自動で実行されるように設定します．**ここまでできれば完成です．**

### トリガーを追加する

1. GASエディタの左側にある**目覚まし時計のアイコン**（トリガー）をクリックします．

2. 右下の **「トリガーを追加」** をクリックします．

3. 次のように設定します．

    | 項目 | 選ぶもの |
    | --- | --- |
    | 実行する関数を選択 | `calendar_reminder_main` |
    | 実行するデプロイを選択 | `Head` |
    | イベントのソースを選択 | `時間主導型` |
    | 時間ベースのトリガーのタイプ | `日付ベースのタイマー` |
    | 時刻を選択 | `午前7時〜8時` など，通知したい時間帯 |

4. **「保存」**をクリックします．

これで毎朝，指定した時間帯に自動でDiscordへ届きます．

> **時刻が正確でないことについて**
> GASの時間主導型トリガーは，**指定した1時間の間のどこかで**実行されます．
> 「午前7時〜8時」を選ぶと，7:00ちょうどではなく7:23などに実行されることがあります．
> これはGASの仕様であり，故障ではありません．

> **1時間おきトリガーは使わないでください**
> このBOTには「同じ日に何度も送らない」という制御が入っていません．
> 1時間おきに設定すると，**1時間ごとに同じ内容が届き続けます．**
> 必ず「日付ベースのタイマー」を選んでください．

### 通知の内容を変えたいとき

`config_calendar.gs` を編集して保存すれば，次回の実行から反映されます．トリガーを作り直す必要はありません．

| やりたいこと | 変更する設定 |
| --- | --- |
| 今日の予定だけにしたい | `enableTomorrowReminder: false` |
| 明日の予定だけにしたい | `enableTodayReminder: false` |
| 予定がない日も通知してほしい | `notifyIfEmpty: true` |
| 説明欄を表示したくない | `showDescription: false` |
| 説明欄をもっと長く表示したい | `descriptionMaxLength: 200` |
| リンクを開いたとき1日だけ表示したい | `calendarLinkView: "day"` |
| リンクを開いたとき月表示にしたい | `calendarLinkView: "month"` |

### 通知する時刻を変えたいとき

トリガーの画面で，作成したトリガーの**鉛筆アイコン**をクリックし，時刻を選び直して保存します．

## 日々の使い方

セットアップが終われば，**普段どおりGoogleカレンダーを使うだけ**です．

- 予定を追加する → 翌朝の通知に自動で含まれます
- 予定を消す → 通知からも消えます
- 新しい種類を増やしたいとき → 色を付け，`config_labels.gs` に追記して `sync_calendar_label_registry` を実行

GASの画面を開く必要はありません．

## うまくいかないとき

### Discordに何も届かない

| 症状 | 対処 |
| --- | --- |
| `test_send_discord_message` も届かない | Webhook URLが正しいか確認．`"` の中に余計な空白や改行が入っていないか見る |
| テストは届くが本番が届かない | 対象日の予定が0件の可能性．実行ログを確認．`notifyIfEmpty: true` にして試す |
| 以前は届いたのに届かなくなった | Discord側でウェブフックを削除していないか確認 |

### 実行時にエラーが出る

| エラーメッセージ | 意味と対処 |
| --- | --- |
| `Discord Webhook URL が未設定です` | `webhookUrl` が初期値のまま．手順1のURLに置き換える |
| `カレンダーを取得できませんでした` | `calendarId` が誤っているか，そのカレンダーを見る権限がない．`"primary"` に戻して試す |
| `次のラベルが内部レジストリへ未登録です` | 手順6の `sync_calendar_label_registry` を実行する．すでに実行済みならログでエラーの原因を確認 |
| `Discord送信に失敗しました。status=404` | Webhook URLが無効．Discordで作り直して差し替える |
| `Discord送信に失敗しました。status=429` | 短時間に送りすぎ．しばらく待つ |

### 通知の内容がおかしい

| 症状 | 対処 |
| --- | --- |
| ラベル名が表示されない | その予定に色が付いていないか，その色を `sync_calendar_label_registry` で覚えさせていない |
| 違うラベル名が表示される | 2つのラベルに同じ色を使っている．`inspect_calendar_labels` を実行してログの「colorId の衝突があります」を確認 |
| 通知したくない予定が届く | `targetEventLabels` が `false` のまま．`CALENDAR_REMINDER_LABELS` に変更する |
| 説明が途中で切れる | 正常な動作．`descriptionMaxLength` の値を大きくすると長く表示できます |
| 時刻がずれている | GASのタイムゾーン設定を確認．`appsscript.json` が `Asia/Tokyo` になっているか |

### 状態を詳しく調べたいとき

**`inspect_calendar_labels`** を実行すると，実行ログに次が出力されます．

- BOTが覚えている「色 ↔ 名前」の対応表
- 今日の各予定の色番号（`colorId`）と，解決されたラベル名
- 同じ色を複数のラベルに使っている場合の警告

ラベル関連の問題は，ほとんどこのログで原因が分かります．
