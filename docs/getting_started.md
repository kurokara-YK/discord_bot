# はじめかた

このBOTを自分のDiscordサーバーで動かすまでの手順です．

**プログラミングの経験は必要ありません．** 所要時間はおよそ30〜60分です．

## はじめに知っておくこと

このBOTは3つを組み合わせて動きます．

```text
Googleスプレッドシート   … 当番表と名簿を書いておく表
        ↓
Google Apps Script      … 通知日になったら表を読んでDiscordへ送る
        ↓
Discord                 … メッセージが届く場所
```

**Google Apps Script（GAS）** はGoogleが無料で提供している「Googleのサーバー上でプログラムを動かす仕組み」です．自分のパソコンの電源が切れていても，設定した時刻に自動で動きます．

## 手順1. DiscordのWebhook URLを取得する

1. 通知を流したいチャンネルの歯車アイコン（チャンネルの編集）を開く
2. **「連携サービス」** を選ぶ
3. **「ウェブフック」** →「新しいウェブフック」を押す
4. 名前を分かりやすいものに変える（例: `当番リマインド`）
5. **「ウェブフックURLをコピー」** を押す

> **注意**
> このURLを知っている人は誰でもそのチャンネルへ投稿できます．
> 他人に見せたり，公開リポジトリに貼り付けたりしないでください．
> 漏れた場合は，同じ画面でウェブフックを削除して作り直します．

<p align="right">(<a href="#getting-started-top">上に戻る</a>)</p>

## 手順2. Apps Scriptにコードを反映する

```sh
cd duty_roster_reminder_discord_bot
clasp push
```

claspを使わない場合は，[script.google.com](https://script.google.com/) で新しいプロジェクトを作り，`gas/` の各 `.js` ファイルを同じ名前で作って貼り付けます．

claspの準備は [development_environment.md](development_environment.md) を参照してください．

<p align="right">(<a href="#getting-started-top">上に戻る</a>)</p>

## 手順3. 当番表を作る

**手作業で表を作る必要はありません．** GASが列も書式もプルダウンも込みで作ります．

### 3-1. 作成先フォルダを決める

Googleドライブで当番表を置きたいフォルダを開き，アドレスバーのURLをコピーします．

```text
https://drive.google.com/drive/folders/フォルダID
```

`gas/config_roster.js` の `templateFolderId` に貼り付けます．マイドライブ直下でよければ空文字 `""` にします．

### 3-2. 年度を設定する

当番表の日付は `9/17` のように年を省略して書けます．年は次の設定から決まります．

```js
fiscalStartYear: 2026,   // 年度の開始年
fiscalStartMonth: 4,     // 年度の開始月（日本の年度なら4）
```

この設定なら `9/17` は2026年，`1/7` は **2027年** になります．秋学期のように年をまたいでも正しく扱われます．

### 3-3. 行数を決める

```js
assigneeColumnCount: 8,   // 「1人目」〜「8人目」の8列を作る
rosterRowCount: 20,       // データ行を20行用意する
```

`assigneeColumnCount` を変えると列が自動で増減します．4 にすれば1人目〜4人目の4列，12 にすれば12列になります．`内容`・`メモ`・`通知済み` の位置も自動でずれるため，列を手で足す必要はありません．

### 3-4. 実行する

Apps Scriptエディタで **`create_roster_spreadsheet`** を選んで実行します．

はじめて実行するときはGoogleから「このアプリはGoogleで確認されていません」という警告が出ます．自分で作ったプロジェクトなので，「詳細」→「（プロジェクト名）に移動」→「許可」と進みます．

実行ログに作成先のURLが出ます．

```text
当番表を作成しました。
  ファイル名 : 当番表
  作成先     : （指定したフォルダ名）
  URL        : https://docs.google.com/spreadsheets/d/....
```

> **この関数は最初の1回だけ使います．** 運用が始まってから実行すると，入力済みの内容が消えます．

<p align="right">(<a href="#getting-started-top">上に戻る</a>)</p>

## 手順4. 設定を仕上げる

`gas/config_roster.js` に，手順1のWebhook URLと手順3のスプレッドシートURLを貼り付けます．

```js
webhookUrl: "https://discord.com/api/webhooks/....",
spreadsheetId: "https://docs.google.com/spreadsheets/d/....",
```

スプレッドシートは**URLをそのまま貼り付けて構いません．** IDだけを取り出す処理が入っています．

変更したら `clasp push` で反映します．

## 手順6. 名簿と当番表を入力する

作られたスプレッドシートを開きます．タブが2つあります．

### 先に名簿を埋める

当番表の担当者はプルダウンから選ぶため，**名簿を先に埋めるとスムーズです．**

| 名前 | Discord ID | メモ |
| --- | --- | --- |
| 山田 太郎 | 123456789012345678 | |
| 鈴木 花子 | 234567890123456789 | |

DiscordユーザーIDの調べ方:

1. Discordの「設定」→「詳細設定」→「開発者モード」をオンにする
2. 対象のユーザーを右クリック →「ユーザーIDをコピー」

IDが分からない人は空欄で構いません．その人は名前だけで通知されます．

### 当番表を入力する

| No. | 担当日 | 通知日 | 1人目 | 2人目 | 内容 | メモ | 通知済み |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 2026/09/17 | 2026/09/11 | | | ガイダンス | 新B3歓迎会もあり | ☑ |
| 2 | 2026/09/24 | 2026/09/18 | 山田 太郎 | 鈴木 花子 | S1 | | ☐ |

- **担当日** … 当番の日．セルをダブルクリックするとカレンダーから選べる
- **通知日** … この日に通知が飛ぶ．空欄なら担当日から自動計算される
- **担当者** … セルをクリックすると**名簿の名前が一覧で出る**ので選ぶ．いない回は空欄
- **内容** … **通知文に載る**．S1，ガイダンスなど
- **メモ** … 自由記入．**通知には使われない**
- **通知済み** … 通知を送ると**自動でチェックが入る**．チェックを外すともう一度送れる

`内容` と `メモ` の違いは，Discordへ送られるかどうかです．

シートの書き方は [sheet_format.md](sheet_format.md) に詳しくまとめています．

## 手順7. 送信内容を確認する

**`preview_message`** を実行します．**この関数は送信しません．** 今日どの回が対象になり，どんな本文が送られるかを実行ログに出すだけです．

```text
今日の日付: 2026-09-18
--------------------------------
3行目（No. 2）
担当日: 9月24日
通知日: 2026-09-18

来週の発表は<@111...>、<@222...>です。よろしくお願いします。
要旨添削は月曜日の13時までに提出しましょう。
内容: S1
--------------------------------
※ まだ送信していません。
```

「今日 通知する回はありません」と出るのは正常です．今日が通知日でないだけです．

名簿の登録漏れは **`check_settings`** で確認できます．

<p align="right">(<a href="#getting-started-top">上に戻る</a>)</p>

## 手順8. 自動送信を設定する

1. Apps Scriptエディタの左メニューから **時計のアイコン（トリガー）** を開く
2. **「トリガーを追加」** を押す
3. 次のように設定する

| 項目 | 値 |
| --- | --- |
| 実行する関数 | `duty_roster_main` |
| 実行するデプロイ | `Head` |
| イベントのソース | `時間主導型` |
| トリガーのタイプ | `日付ベースのタイマー` |
| 時刻 | `午前8時〜9時` など |

**毎日実行で問題ありません．** 通知日でない日は何も送られません．

GASの時間主導型トリガーは「8時ちょうど」ではなく「8時〜9時のどこか」で実行されます．分単位の指定はできません．

## 日々の運用

### 担当者を入れ替える

担当者のセルをクリックし，**プルダウンから別の人を選ぶだけ**です．名簿に無い名前は入力できないため，打ち間違いが起きません．

すでに通知を送った回をもう一度送りたい場合は，`通知済み` 列の**チェックを外します．**

### 日程が変わった

担当日と通知日のセルを直接書き換えます．セルをダブルクリックするとカレンダーから選べます．

### 文面を変えたい

Discordへ送る文面は `gas/messages.js` にあります．
設定ファイルではなく，こちらを編集してください．

どの文面を使うかは `gas/config_roster.js` の `messageSet` で指定します．

```js
messageSet: "presentation",   // messages.js の名前を書く
```

### 学期が変わった

新しいシートを作り，`rosterSheetName` と `fiscalStartYear` を変更します．

## うまくいかないとき

まず **`check_settings`** を実行し，実行ログを確認してください．

| 症状 | 対処 |
| --- | --- |
| 「シートが見つかりません」 | `rosterSheetName` が実際のタブ名と一致しているか |
| 「spreadsheetId が未設定です」 | `config_roster.js` にURLを貼り付ける |
| 「Webhook URL が未設定です」 | `webhookUrl` に `https://` から始まるURLを貼り付ける |
| 通知が飛ばない | `preview_message` で今日が対象日か確認する |
| メンションされない | `check_settings` で登録漏れを確認する |
| 日付が1年ずれる | `fiscalStartYear` が正しいか確認する |
| 担当者が入力できない | プルダウンのため名簿に無い名前は入らない．名簿へ追加する |
| 通知が飛ばない | `通知済み` にチェックが付いていないか確認する |
