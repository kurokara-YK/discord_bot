# 使いはじめる

Googleアカウントがあれば，無料で使えます。
プログラムを書き換える必要はありません。

所要時間は30分ほどです。

---

## 1. Discord の Webhook URL を用意する

通知を送りたいチャンネルで，次の順に開きます。

1. チャンネル名の右の歯車（チャンネルの編集）
2. 連携サービス
3. ウェブフック → 新しいウェブフック
4. 「ウェブフックURLをコピー」

> **注意**
> このURLを知っている人は，誰でもそのチャンネルへ投稿できます。
> 他人に見せたり，公開リポジトリへ載せたりしないでください。
> 誤って公開した場合は，Discord 側でウェブフックを削除して作り直します。

---

## 2. Apps Script プロジェクトを作る

1. [script.google.com](https://script.google.com/) を開く
2. 「新しいプロジェクト」
3. プロジェクト名を分かりやすいものにする（例: シフトリマインド）

`gas/` の中のファイルを，同じ名前で作って貼り付けます。
ファイル名の `.js` は `.gs` になります（`config_shift.js` → `config_shift.gs`）。

`appsscript.json` は「プロジェクトの設定 →『appsscript.json』マニフェスト ファイルを
エディタで表示する」にチェックを入れると編集できます。

clasp を使う場合は [development_environment.md](development_environment.md) を見てください。

---

## 3. 設定を書く

`config_shift.gs` の上のほうを書き換えます。

```js
webhookUrl: "https://discord.com/api/webhooks/...",   // 1でコピーしたURL
spreadsheetId: "ここにシフト表のスプレッドシートのURLを入れてください",  // まだそのまま
templateFolderId: "",   // マイドライブ直下でよければ空文字
```

`fiscalStartYear` を，イベントの年に合わせます。

```js
fiscalStartYear: 2026,   // 日付を「11/1」と書いたとき，何年とみなすか
```

---

## 4. スプレッドシートを作る

エディタ上部の関数の一覧から `create_shift_spreadsheet` を選び，「実行」を押します。

初回は権限の確認が出ます。「詳細」→「（プロジェクト名）に移動」→「許可」と進みます。

実行ログにURLが出るので，`config_shift.gs` の `spreadsheetId` に貼り付けます。

```
シフト表を作成しました。
  URL : https://docs.google.com/spreadsheets/d/xxxxx/edit
```

---

## 5. 日程シートに，その日が何の日かを書く

作られたスプレッドシートの「日程」シートを開きます。
最初から例が入っているので，自分のイベントに合わせて書き換えます。

| 日付 | その日の予定 | 作業開始 || 作業終了 || 予定を送る || 送信済 | お疲れさまを送る || 送信済 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | 時 | 分 | 時 | 分 | 時 | 分 | | 時 | 分 | |
| 11/1 | 準備の日 | 07 | 00 | 20 | 00 | 06 | 30 | ☐ | 20 | 00 | ☐ |
| 11/2 | Day1 本番 | 09 | 00 | 18 | 00 | | | ☐ | | | ☐ |

**行を足せば，何日でも増やせます。**

**作業時刻と通知時刻は別のもの**です。

- **作業開始・作業終了** … その日に何時から何時まで動くか。通知文に出ます
- **予定を送る・お疲れさまを送る** … 通知そのものの時刻

準備日は7時開始だから予定は6時半に，本番日は9時開始だから8時に，
というように日ごとに変えられます。

通知時刻を**空にすると，作業時刻から決まります**
（予定は作業開始の30分前，お疲れさまは作業終了と同じ時刻）。
毎日おなじでよければ空欄のままで構いません。

日付はダブルクリックでカレンダーから選べます。
時刻の列は15分刻みのプルダウンです。

---

## 6. 名簿とシフト表を埋める

### 名簿

| 名前 | Discord ID |
|---|---|
| 山田 太郎 | 111111111111111111 |

Discord ID は，Discord の 設定 → 詳細設定 → 開発者モード をオンにしてから，
ユーザーを右クリック →「ユーザーIDをコピー」で取れます。

**名簿を先に埋めてください。** シフト表の担当者は名簿から選ぶ形式のためです。

Discord ID が空でも構いません。その人は通知文に名前だけが出ます。

### シフト表

**最初から30行の空欄**が用意されています。プルダウンから選んで埋めていきます。

| No. | 日付 | 開始時刻 || 終了時刻 || 1人目〜 |
|---|---|---|---|---|---|---|
| | | **時** | **分** | **時** | **分** | |
| 1 | 11/2 | 10 | 30 | 12 | 00 | 山田 太郎 |

| 列 | 入力のしかた |
|---|---|
| 日付 | プルダウン（日程シートに書いた日） |
| 開始・終了 | 時と分をそれぞれプルダウンで選ぶ |
| 1人目〜 | プルダウン（名簿の名前） |

分は15分刻み（`00` `15` `30` `45`）です。
開始と終了をそれぞれ選ぶので，**コマの長さは自由**です。
1時間でも30分でも1時間15分でも作れます。

---

## 7. トリガーを登録する

`setup_triggers` を実行します。通知に必要な2本のトリガーが登録されます。

```
トリガーを登録しました。shift_reminder_main : 15分おき

  事前通知     : 60分前, 15分前
  今日の予定   : 日程シートの「予定を送る」時刻
  お疲れさま   : 日程シートの「お疲れさまを送る」時刻
```

15分おきに動き，そのつど「いま送るものはあるか」を判定します。
通知の時刻は日程シートに書くため，トリガーは1本で足ります。

これで準備は終わりです。

---

## 動きを確かめる

`check_settings` を実行すると，設定と表の状態が出て，
Discord へテストメッセージが1通届きます。
シフトの通知は送りません。

```
[通知のタイミング]
  事前通知   : 60分前, 15分前
  交代の案内 : する
  朝のまとめ : 8:00

[日程] 3日 / コマ枠 39件

[シフト表] 39行
  担当者なし : 4行
  通知しない : 0行

[名簿]
  Discord ID 未登録 : 田中 次郎

[Discord] テストメッセージを送信しました。チャンネルを確認してください。
```

うまく動かないときは，まずこれを実行します。

### 通知を試す

シフト表の日付を今日に書き換え，開始時刻を「いまから1時間後」にして
`shift_reminder_main` を実行すると，実際に通知が届きます。

試したあとは，通知済みのチェックを外しておきます。

---

## 当日の運用

| したいこと | 操作 |
|---|---|
| すべての通知を止める | 日程シートの「通知を停止」にチェック |
| ある枠だけ止める | シフト表「通知しない」にチェック |
| 事前通知をもう一度送る | シフト表の「通知済み」のチェックを外す |
| 今日の予定・お疲れさまを再送する | 日程シートの「送信済」のチェックを外す |

すべてスプレッドシート上の操作です。スマホからでもできます。
