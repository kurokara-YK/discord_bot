# スプレッドシートの形式

シフト表は3つのシートでできています。
シートは `create_shift_spreadsheet` が作るため，手で列を用意する必要はありません。

| シート | 役割 | 人が編集するか |
|---|---|---|
| 日程 | その日の予定・作業時間帯・通知時刻。全体の通知停止 | する |
| シフト表 | コマ枠と担当者 | 担当者を割り当てる |
| 名簿 | 名前・Discord ID・担当コマ数 | する |

---

## 日程シート

**その日が何の日か**，**作業の時間帯**，**通知を送る時刻**を書く表です。

見出しは2段になっています。

| 日付 | その日の予定 | 作業開始 || 作業終了 || 予定を送る || 送信済 | お疲れさまを送る || 送信済 | メモ |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | 時 | 分 | 時 | 分 | 時 | 分 | | 時 | 分 | | |
| 11/1 | 準備の日 | 07 | 00 | 20 | 00 | 06 | 30 | ☐ | 20 | 00 | ☐ | |
| 11/2 | Day1 本番 | 09 | 00 | 18 | 00 | | | ☐ | | | ☐ | |

**行を足せば，何日でも増やせます。**

### 作業時刻と通知時刻は別のもの

ここが分かれているのが大事なところです。

| 列 | 意味 |
|---|---|
| **作業開始・作業終了** | その日に何時から何時まで動くか。通知文に出ます |
| **予定を送る** | その日の予定を知らせる時刻 |
| **お疲れさまを送る** | その日の終わりをねぎらう時刻 |

準備日は 7:00 開始なので予定は 6:30 に送りたい，
本番日は 9:00 開始なので 8:00 でよい，というように
**日によって変わる**ため，日ごとに書けるようにしています。

### 通知時刻を空にしたとき

作業時刻から自動で決まります。

| 通知 | 空欄のときの時刻 |
|---|---|
| 予定を送る | 作業開始の **30分前** |
| お疲れさまを送る | 作業終了と**同じ時刻** |

毎日おなじ決めかたでよければ，**空欄のままで構いません。**
変えたい日だけ書きます。

### 作業時刻とシフトを合わせる

**作業終了より後にコマを置かないでください。**
「お疲れさま」がシフトより先に届いてしまいます。

`check_settings` を実行すると，作業時間の外にあるコマを警告します。

### 送信済

通知を送るとチェックが入ります。
**もう一度送りたいときは，チェックを外します。**

シート上で「今日の分は送られたか」が一目で分かります。

### 入力のしかた

| 列 | 入力のしかた |
|---|---|
| 日付 | **ダブルクリックでカレンダーが開きます** |
| その日の予定 | 自由に書きます（「準備の日」「Day1 本番」など） |
| 時刻の列 | 時と分をそれぞれプルダウンで選びます（15分刻み） |

### 届く通知

```text
【本日のシフト】11月1日(日) 準備の日 7:00〜20:00
@山田 太郎
  10:00〜11:00
@鈴木 花子
  12:00〜13:00
```

```text
【本日の業務終了】11月1日(日) 準備の日 7:00〜20:00
本日の業務は終了です。お疲れさまでした。
片付けと戸締まりをお願いします。

本日の担当: @山田 太郎、@鈴木 花子
```

### 通知を停止

表の下に「通知を停止」のチェックボックスがあります。
チェックを入れると**すべての通知が止まります。**

## シフト表シート

**最初から30行の空欄が用意されています。** プルダウンから選んで埋めていきます。

見出しは2段になっています。

| No. | 日付 | 開始時刻 || 終了時刻 || 1人目〜8人目 | メモ | 通知しない | 通知済み |
|---|---|---|---|---|---|---|---|---|---|
| | | **時** | **分** | **時** | **分** | | | | |
| 1 | 11/2 | 10 | 30 | 12 | 00 | 山田 太郎 … | | ☐ | ☐ |

行が足りなくなったら，シート上で行を足してください。

### 入力はプルダウンで

手で打つと表記がゆれ（「9:00」と「09:00」など），
同じコマが別のものとして扱われてしまいます。
そのため，主な列はプルダウンから選ぶ形にしています。

| 列 | 入力のしかた |
|---|---|
| 日付 | プルダウン。**日程シートに書いた日**から選びます |
| 開始・終了 | 時と分をそれぞれプルダウンで選びます |
| 1人目〜8人目 | プルダウン。名簿の名前から選びます |

日程シートに行を足すと，日付の候補も自動で増えます。

### コマの長さは自由

分の候補は15分刻み（`00` `15` `30` `45`）です。
開始と終了をそれぞれ選ぶため，**コマの長さは決まっていません。**

| 作りたいコマ | 開始 | 終了 |
|---|---|---|
| 1時間 | 10:00 | 11:00 |
| 30分 | 10:00 | 10:30 |
| 15分 | 10:00 | 10:15 |
| **1時間15分** | 10:00 | **11:15** |
| 45分 | 10:15 | 11:00 |

同じ表の中で長さの違うコマを混ぜても構いません。

刻みを変えたい場合は `config_shift.js` の `minuteStep` を書き換えます。
**トリガーの間隔（`triggerMinutes`）も同じ値に合わせてください。**

分を選ばなかった場合はちょうどの時刻（00分）として読みます。

終了が開始より前になっている行は，書き間違いとみなして通知しません。

### 担当者の入力

担当者のセルをクリックすると，**名簿に登録されている名前が一覧で出ます。**

名簿に無い名前は入力できません。制限ではなく，**打ち間違いを防ぐため**です。
シフト表と名簿で名前が1文字でも違うと，その人はメンションされません。

新しい人を担当者にしたい場合は，**先に名簿へ追加**してください。
名簿に行を足すと，プルダウンの候補にも自動で追加されます。

人数がコマによって違う場合は，埋まっているところだけが読まれます。
担当者が1人もいない枠は通知されません（送る相手がいないため）。

### 通知済み

その枠の事前通知を**すべて送り終えるとチェックが入ります。**

既定では1時間前と15分前の2回送るため，
1時間前を送った時点ではまだチェックは入りません。

**もう一度送りたいときは，チェックを外します。**
外すと記録も消え，最初から送り直されます。

### 通知しない

その枠だけ通知を止めたいときに，チェックを入れます。
チェックを入れた行は灰色になります。

## 名簿シート

| 名前 | Discord ID | 担当コマ数(自動) | メモ |
|---|---|---|---|
| 山田 太郎 | 111111111111111111 | 4 | |
| 鈴木 花子 | 222222222222222222 | 2 | 当日のみ参加 |

| 列 | 内容 |
|---|---|
| 名前 | シフト表のプルダウンに出る名前です |
| Discord ID | 18桁前後の数字。メンションに使います |
| 担当コマ数(自動) | シフト表を集計します。偏っていないか確認できます |

`担当コマ数` が `#REF!` になっている場合は，`repair_member_formula` を
実行すると直ります。シフト表より先に数式が入ってしまうと，
参照が壊れたまま固定されるためです。
| メモ | 自由に書けます。通知には使いません |

### Discord ID の調べかた

1. Discord の 設定 → 詳細設定 → 開発者モード をオンにする
2. ユーザーを右クリック → 「ユーザーIDをコピー」

### Discord ID が空の人

シフト表からは消えません。通知文には**名前だけ**が出ます。

```
【まもなく交代】10:30〜12:00
次の担当: <@111111111111111111>、鈴木 花子（ID未登録）
```

誰が担当なのかは分かったまま，その人にはメンションが飛びません。

## 通知を止める2つの方法

止めたい範囲によって，使う場所が違います。

| 止めたい範囲 | 場所 | 操作 |
|---|---|---|
| すべて | 日程シートの「通知を停止」 | チェックを入れる |
| その枠だけ | シフト表「通知しない」 | チェックを入れる |

いずれもスプレッドシート側にあります。
当日スマホからシートを開いて切り替えられ，再デプロイは要りません。

判定は上から順に見て，1つでも止まっていれば送りません。

## 列や行を増やす

### 行を増やしたい

シフト表や日程シートに，そのまま行を足してください。

### 担当者を9人以上にしたい

`config_shift.js` の `assigneeColumnCount` を変えて，
`create_shift_spreadsheet` でシートを作り直します。

### 通知のタイミングを増やしたい

`config_shift.js` の `beforeMinutes` に足します。

```js
beforeMinutes: [60, 30, 15],   // 30分前を足す
```

**シフト表の形は変わりません。** 「通知済み」は1列のままで，
3回すべて送り終えたときにチェックが入ります。
